# Store Data Analysis – Excel

## Project Overview
This project focuses on analyzing store sales data using Microsoft Excel to identify sales trends, customer purchasing patterns, and business performance.

## Tools & Techniques
- Microsoft Excel
- Pivot Tables
- Data Analysis
- Data Visualization
- Interactive Slicers

## Dashboard Features
- Monthly Orders vs Sales
- Sales: Men vs Women
- Order Status Analysis
- Top 5 States by Sales
- Age vs Gender Analysis
- Orders by Channel

## Interactive Filters
- State-wise
- Quarter-wise

## Business Objective
To analyze store performance, understand customer behavior, identify sales patterns, and generate actionable business insights.
